# 生产实习 — 课时1：使用量潮第二大脑

课时 "生产实习" 的第一个课时，讲用量潮第二大脑（`quanttide` 根仓库）完成一次从"开工作区"到"逐级提交"的完整实操，包含 3 个场景（Scene），顺序推进。

## 场景列表

| 场景 | 标题 | 描述 | 前置依赖 |
|------|------|---------|---------|
| Scene 1 | 安装与开工作区（Git submodule 的坑） | 克隆含子模块的第二大脑、初始化并打开工作区，避开子模块常见坑 | 无 |
| Scene 2 | 理解信息架构、初始化下级第二大脑与新建工作区 | 认识三轴与统一结构，按模板初始化一个新的下级第二大脑并接入工作区 | Scene 1 |
| Scene 3 | 逐级提交 | 按"子模块提交→父仓库更新指针"的层级，逐级提交并推送 | Scene 1-2 |

## 场景关系

```mermaid
flowchart LR
    s1[Scene 1<br>安装与开工作区<br>(Git submodule 的坑)] --> s2[Scene 2<br>理解信息架构<br>初始化下级第二大脑<br>新建工作区]
    s2 --> s3[Scene 3<br>逐级提交]
```

每个场景录制一段短视频，学员按序观看并操作。Scene 3 完成后即完成本课时。
