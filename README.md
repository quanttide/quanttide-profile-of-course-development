# quanttide-profile-of-course-development

课程开发档案。记录真实问题如何被一步一步分解和解决——目录结构即内容：三层展开同一个问题，每层各有用途。

## 目录结构

课程按「方向 → 课节 → 步骤」三层组织：

- **方向**（`devops/`、`vibe-coding/`）——产品线。盘点业务版图从这层看。
- **课节**（`lesson1-release/`）——能独立交付的最小完整单元。排课、卖课、写大纲以它为单位。
- **步骤**（`01-update-version.json`、`03-commit.json` …）——问题分解的执行序列，按编号即顺序。做课的人照它铺内容，学的人照它一步步走。

步骤的三种文件各有消费者：`.json` 给机器（对接平台服务端 API，与 `lessonN/` 的 Markdown 按 CONTRIBUTING 的双格式工作流同步）、`.mp4` 给演示、`.md` 给「为什么这么做」。`e1-` 前缀是分解时预判的岔路——教学刻意把出错与救援做成内容，失败是学习的一部分。
